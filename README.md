# SunHome Spain AI Consultant

## Overview

SunHome Spain AI Consultant is an AI-powered assistant designed to help clients select real estate in Spain based on their goals, budget, lifestyle preferences, and investment plans.

The assistant uses a structured knowledge base and personalized consultation workflows to provide relevant recommendations and answer client questions.

## Project Goal

Develop an AI consultant capable of:

* Understanding client needs
* Providing personalized property recommendations
* Answering questions using a knowledge base
* Presenting suitable real estate options
* Supporting the client consultation process

## Features

* Real estate consultation
* Knowledge base search
* Personalized recommendations
* Question and answer support
* Client needs analysis
* Property selection guidance
